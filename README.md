## 🚀 Featured Projects

### 🔬 XM-ViT Palm
**Explainable Multi-task Vision Transformer for Soft Biometric Attribute Estimation**

A research-oriented deep learning framework for estimating demographic attributes from palm impressions using a Vision Transformer.

**Highlights**
- Multi-task classification and age regression
- Explainability using Grad-CAM
- Subject-disjoint dataset evaluation
- 93.27% gender classification accuracy
- 4.29-year age regression MAE

**Stack:** Python, PyTorch, Vision Transformers, OpenCV

[🔗 View Repository](https://github.com/Shuvranil9T5/XM-ViT-Palm)

**Intelligent Building Energy Flexibility Aggregator**

An AI-powered energy management system for electricity forecasting, demand response and carbon-aware scheduling.

- Flexible load identification
- Cost and carbon optimization
- Interactive analytics dashboard
- Automated PDF reporting

**Stack:** Python, FastAPI, React, Scikit-learn
